# 标准化数据契约

## daily.csv

| 字段 | 类型 | 解释 |
|---|---|---|
| date | YYYY-MM-DD | 日粒度，午夜时间，无时区变换 |
| sku | string | 不含真实身份的商品标识 |
| demand | nonnegative number | 已履约发货量代理，单位为件/册；公开数据为合成件数 |

键为 `(date, sku)`，不得重复；必须是完整的全商品日历面板。空白、NaN、无穷值和负需求被拒绝。导出日期完全缺失、商品停售、缺货、尚未上市与真实零销量必须先在准备阶段判断。模型不会默默补齐缺失数据。

真实数据准备需要：核实发货字段与净销售、退货口径；先在商品日粒度汇总；检查源日期；在采集完整且确认无记录表示零发货的范围才补零；用验证期以前的记录选择商品集合。商品代码相同并不保证商品定义跨版本不变，需单独维护主数据映射。

## products.csv

| 字段 | 约束 | 解释 |
|---|---|---|
| sku | 唯一，集合与 daily 完全一致 | 商品标识 |
| lead_time_days | 正整数 | 情景补货提前期 |
| batch_size | 正整数 | 情景订货批量 |
| unit_cost | 有限正数 | 情景成本单位，不是原业务成本 |
| family / regime | 可选 | 公开生成器的预设组与需求形态 |

缺乏采购与收货时间戳时不能宣称提前期来自真实供应商；缺乏可售库存、待发、在途及缺货日志时不能宣称复现真实仓库历史。

## annual.csv

| 字段 | 约束 | 解释 |
|---|---|---|
| sku | string | 跨年关联的规划商品/商品群标识 |
| year | 连续整数 | 历史年度 |
| sales | 有限非负数 | 年度净实销代理 |
| shipments | 有限非负数 | 年度发货背景字段，当前不进入预测公式 |
| family | string | 规划系列的中性分组 |

键为 `(sku, year)`，年度与商品面板必须完整。新书无历史不能按零销量直接混入成熟商品回测。多个新版本如果共享同一历史轨迹，需要明确其继承关系；本地验证采用去重后的代表轨迹，仍可能有版本映射和幸存者偏差。

## 来源与可追溯性

`data/demo/manifest.json` 包含合成数据模式、种子及三个 CSV 的 SHA-256。`reports/demo/summary.json` 记录用于该次实验的数据哈希。公开入口不读取真实 ERP、源 Excel、真实参数或身份映射。

私有评估命令只读取显式指定的标准化 CSV，并强制结果目录在仓库外。原导出、本地提取代码、身份映射、真实结果及其来源路径不属于公开文件清单。
