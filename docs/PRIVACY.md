# 隐私、来源与发布范围

## 私有来源如何参与项目

项目问题与数据契约参考作者获授权读取的本地出版发行材料，包括日发货、退货和跨年首发规划。私有准备阶段在电脑上进行质量检查和标准化，随后调用与演示完全相同的算法入口进行离线验证。原始身份映射与所有私有回测结果均保留在仓库外。

本仓库不附真实原始记录、真实聚合序列、真实版本映射、真实客户或员工、原始商品标识、订单、成本、计划量和本地来源路径。公开数据完全由 `supplychain/data.py` 生成器的固定随机种子与人工假设生成；它没有私有数据读取参数，也没有读取私有数据的代码。

采用这种发布方式，是因为仅替换商品名、日期或缩放销量仍可能暴露真实业务结构。公开结果可以说明算法怎样运行；关于私有数据的具体测量只能在本地材料中查阅，不能由公开演示指标反推为真实企业结果。

## 包含什么

- 本项目新建的算法、实验入口、测试和说明。
- 中性商品标识、独立合成的日数量和年度数量。
- 人工设定的情景交期、批量、成本、库存与容量。
- 仅由上述公开合成输入产生的结果表、图和输入哈希。

## 发布检查

`python scripts/privacy_check.py` 做文件类型白名单检查、私有标识/联系方式/凭证/本地路径模式检查，在临时目录重新生成合成数据并比较哈希，验证报告输入哈希与合成清单一致。发布时另在本地对真实身份词表进行私有扫描，词表不进入仓库。

模式扫描无法证明任意文本均已匿名。添加新文件、修改数据或导出图表后需重新审阅内容；只有本项目固定生成器的合成数据通过了相应复算检查。`.gitignore` 只是辅助，发布文件清单和内容核验才是边界。

`evaluate` 私有模式拒绝在仓库目录下输出结果；源文件和本地结果不应加入 Git 历史。命令本身不联网，也不调用模型服务。

## 简历表达

可以说明从真实业务数据结构出发、完成本地离线评估，并提供合成数据复现版。不得把合成 WAPE、仿真满足率或优化目标值写成公司的真实经营改善；也不得把本次新增实验追溯为先前已落地的供应链系统。
