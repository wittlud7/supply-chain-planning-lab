# 03 首印风险与印量产能分配

**问题**：年度实销存在下滑与版本变化时，怎样表达过量和缺量的成本；总印量受限时怎样分配整数批次。

实现位于 [production.py](../../supplychain/production.py)。年度实验对比沿用上年、趋势融合和经验比例残差报童策略；仅用目标年之前的残差，测试三档成本比。独立的下一期产能实验以点预测作为计划目标，加入固定批量、最少起印批次和总印量约束，通过 MILP 求解，并与同约束可行贪心比较。

验收包括：未来年度实际值不改变先前计划；产能不超限；批量与起印门槛满足；零容量仍有可行缺量解；小规模问题的最优目标与全量穷举一致。求解结果需包含最优状态、对偶界和间隙。

详见 [公式与边界](../../docs/METHODS.md) 和 [结果](../../reports/demo/RESULTS.md)。当前过量是滞销风险代理，产能是单周期总件数；不包含印厂机台排序或实际纸张约束。
