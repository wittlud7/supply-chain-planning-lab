# 01 商品需求预测

**问题**：用已履约发货量建立可核查的需求预测基线，观察长尾和间歇需求下选模是否稳定。

实现位于 [forecast.py](../../supplychain/forecast.py)。5 个模型共享接口 `predict(history, horizon, model)`，42 日时间验证后冻结商品模型选择，最终 56 日按 8 个起点评估。输出逐商品逐日预测、训练截止日、模型来源及误差；保留全零标度和零分母的未定义指标。

验收包括：改变测试期未来实际值不改变先前选模；训练截止日始终早于预测起点；每个模型的测试日期互不重复；周期完全重复的序列，其周朴素预测误差为零。

读取 [结果表](../../reports/demo/RESULTS.md) 和 [方法](../../docs/METHODS.md)。公开数据是独立合成数据；不能据此断言某方法在真实库存约束下恢复了潜在需求。
