# 02 ABC/XYZ 分层库存与补货

**问题**：按商品价值与波动特征设定补货策略，在同样需求与约束下比较服务与库存投入。

实现位于 [inventory.py](../../supplychain/inventory.py)。测试前完成分层，每 7 日在当天需求观察后复核，下单量按批量取整，固定提前期后日初到货。模型采用丢失销售，不把缺量滚成积压订单；比较统一安全系数、ABC 分层预测和额外覆盖天数策略。

输出日库存与到货流水、满足率、未满足量、期末库存与在途、成本分项，以及 27 组参数情景。验收以日库存平衡、全周期库存守恒、批量约束和到货时机为主。

查看 [方法中的事件顺序与公式](../../docs/METHODS.md) 和 [结果](../../reports/demo/RESULTS.md)。库存与交期来自情景参数，满足率不代表真实仓库改善。
